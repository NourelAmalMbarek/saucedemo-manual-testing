## 2. Project Objective

The objective of this project is to verify the functionality of the main features of the SauceDemo web application through manual testing and to identify, document, and report any defects found during test execution.

## 3. Application Overview

SauceDemo is a web-based e-commerce application that allows users to log in, browse products, view product details, sort products, add and remove products from the shopping cart, and complete a checkout process.
